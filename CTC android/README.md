# CTC Tag Checker — Android

Перебор клан-тегов Standoff 2 прямо на телефоне (Android 11+). Без ПК, без root, без эмулятора.

## Сборка APK (через GitHub, бесплатно)
1. Зарегистрируйтесь на github.com → New repository → любое имя → Create.
2. Add file → Upload files → перетащите ВСЁ содержимое папки проекта (включая папку .github). Commit changes.
   Если папка .github не загрузилась (скрытая) — Add file → Create new file, имя `.github/workflows/build.yml`, вставьте текст файла build.yml.
3. Вкладка Actions → Build APK — сборка идёт ~3–5 минут.
4. Откройте завершённую сборку → внизу Artifacts → CTC-Tag-Checker-apk → скачается zip, внутри app-debug.apk.
5. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников).

## Настройка на телефоне (один раз)
1. Откройте CTC Tag Checker → выберите режим, буквы/цифры, паузу.
2. «Включить службу» → Спец. возможности → CTC Tag Checker → Вкл.
   На Android 13+ если переключатель серый: Настройки → Приложения → CTC Tag Checker → ⋮ → «Разрешить ограниченные настройки».
3. Если нужны цифры: в Gboard включите «Ряд цифр» (Настройки Gboard → Настройки → Ряд цифр).
4. «Показать панель» → откройте Standoff 2 → окно переименования клана → тапните по полю, чтобы открылась клавиатура.
5. На панели «Калибр.» → тапайте по подсказкам: поле, ⌫, место галочки, кнопка проверки (или Пропустить), каждая клавиша.
6. Введите вручную заведомо занятый тег → «✗цвет». Введите свободный → «✓цвет». (Повышает точность.)
7. «Старт». «Стоп» — в любой момент. Продолжит с места остановки.

Свободные теги: в приложении → «Свободные теги / копировать».

## Если не работает
- Сборка упала: Actions → красная сборка → шаг с ошибкой → скопируйте текст ошибки и пришлите.
- «Скриншот не удался»: игра может блокировать скриншоты — сообщите.
- Делайте паузу 900+ мс, чтобы не триггерить защиту игры.
